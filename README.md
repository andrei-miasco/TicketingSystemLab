<h1>Ticketing System Homelab</h1>

<h2>Description</h2>
In this lab we will be using Spiceworks to simulate the following: How to create a new ticket, how to close the ticket once a resolution has been made, and how to escalate a ticket if needed.
<br />


<h2>Languages and Utilities Used</h2>

- <b>SpiceWorks</b>
